📘 NumPy Notes (Python)

This repository contains well-organized notes and examples for NumPy, designed to help beginners and learners understand numerical computing and array operations in Python.

📌 About NumPy

NumPy (Numerical Python) is a fundamental Python library used for:

Working with arrays and matrices

Performing mathematical and statistical operations

Supporting data science, machine learning, and scientific computing
